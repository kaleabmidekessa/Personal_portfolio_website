# Project Title & Overview
A Personal Portfolio Website to later add AI engineering features

# Tech Stack
Python, Django, SQLite, HTML5, and CSS3

# Key_Ffeatures
Database- driven About, Experience, Projects, and Skills sections managed via the Django Admin Panel, plus downloadable PDF resume support.
# Local Setup Instructions
```bash
git clone https://github.com/kaleabmidekessa/Personal_portfolio_website
cd Personal_portfolio_website
python -m venv pvenv
source pvenv/Scripts/activate 
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Then open http://127.0.0.1:8000 in your browser.
